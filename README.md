## Descripción del proyecto

Este proyecto consiste en un sistema gestor de base de datos SQL sencillo, desarrollado en C++ y basado en la estructura de datos Árbol B+.

## Tecnología necesaria

- **Lenguaje:** C++ (estándar C++11 o superior)
- **Compilador:** g++ (parte de GCC)
- **Herramienta de build:** make
- **Sistema operativo:** Cualquiera con soporte para g++/make (Linux, WSL en Windows, macOS)

## Compilar
```bash
make
./bd_sql
```
